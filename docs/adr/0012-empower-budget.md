# Powerful Pieces uses an Empower budget

Setup no longer picks exactly N Empowered Pieces. Each Side spends a Host-tuned budget (default 4, range 3–20; Campaign may override) using per-PieceType Empower costs, and must spend exactly the full budget. Chosen so Queen+King is a real ask and alternate armies (e.g. Rook+Bishop+Pawn) are first-class.
