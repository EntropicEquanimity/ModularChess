# FIDE Law is not Core

Core is occupancy, Piece identity, Pattern, and Turn. FIDE-specific rules — King mobility, promotion, slider range, Check obligations, who moves first, Checkmate, Stalemate, and FIDE draws — are Law. Versus Activities use FIDE Law. Roguelike supplies Roguelike Law. FIDE is not a Mode. Rejected: making FIDE a selectable Mode; special-casing mate inside Core; expressing Roguelike as a forced Mode stack.
